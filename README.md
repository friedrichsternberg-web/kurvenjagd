# Serpa – die Motorrad-App

**[serpa-app.de](https://serpa-app.de/)** · kostenlos · ohne App-Store · deutsch

Serpa ist ein Motorrad-Routenplaner, der **kurvige Strecken** statt der
schnellsten findet, ein **Reiseplaner** für mehrtägige Motorradreisen mit
Etappen, Mitfahrern und gemeinsamer Kasse, eine **Aufzeichnung** eigener
Ausfahrten mit Kurven-Score und Schräglage, und ein **Freunde-Bereich**, in
dem Gruppen Touren teilen und sich mit „Ich fahre jetzt“ spontan zum Fahren
verabreden.

- Kurvigkeit in Grad pro Kilometer, Rundtouren, GPX-Import und -Export
- Reise planen: Tage, Etappen, Reisekarte, Kasse, Chat, Notizen
- Freunde: Gruppen, geteilte Touren, Kommentare, „Ich fahre jetzt“
- Läuft im Browser und als Web-App auf dem Startbildschirm (iPhone, Android)

Reines HTML, CSS und JavaScript ohne Build-Schritt. Karten von
OpenStreetMap, Routing über BRouter, Konto und Server über Supabase.
